# Brian McCarthy - Professional Portfolio

A professional, single-page portfolio website built for ABC Consultant clients.

## Technologies Used
- **React**: For building the user interface with functional components and hooks.
- **Tailwind CSS**: For modern, responsive styling and utility-first design.
- **Motion (motion/react)**: For smooth animations and transitions.
- **Lucide React**: For beautiful, consistent iconography.
- **Vite**: For a fast development environment and optimized production builds.
- **JavaScript (ES6+)**: Used exclusively for logic and component architecture.

## Key Features
- **About Me**: A personal summary and profile section.
- **Interactive Navigation**: A responsive header with links that highlight on hover and smooth scroll to sections.
- **Skills Showcase**: A grid of technical skills with logos and years of experience.
- **Project Details**: A detailed list of professional projects and accomplishments.
- **Recommendations System**: 
  - Dynamic display of testimonials with quote icons.
  - Interactive form to submit new recommendations.
  - Confirmation popup toast after successful submission.
- **Home Navigation**: 
  - A "Home" icon in the navigation bar.
  - A persistent "Back to Top" button that appears on scroll with a "Home" tooltip.
- **Responsive Design**: Fully optimized for desktop and mobile viewing.
